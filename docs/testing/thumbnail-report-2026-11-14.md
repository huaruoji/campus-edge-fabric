# Report：thumbnail 单 Worker 与双 Worker 对照

日期：2026-11-14（Asia/Shanghai）。执行与整理角色：D。方法见 [Procedure](thumbnail-procedure.md)，未四舍五入的结果见 [精简证据 JSON](evidence/thumbnail-2026-11-14.json)。

## 1. 结论

100 张固定 BSDS300 图片，在两个单 Worker 条件和一个双 Worker 条件下各运行三次。双 Worker 中位端到端吞吐 **3.3055 images/s**，比最快单 Worker **提高 26.17%（S=1.262×）**，相对于两条单 Worker 吞吐之和的聚合效率 **η=88.26%**。

9 轮正式测量的 **900/900 个输出**通过 SHA256、PNG 解码、参考尺寸和逐像素校验，9 轮预热的 **144/144 个输出**也通过；所有任务的最终 attempt 均为 1。单 Worker 条件只由对应设备贡献结果，三轮 pool 均由两个 Worker ID 共同完成。

本结果支持“本次配置下，双 Worker 对这批图片的服务吞吐高于任一单 Worker”。尚不能据此宣称设备已饱和、调度已接近理论最优、GPU 加速成立，或更多设备必然继续提速。独立物理设备身份和完整硬件信息仍待 B 补充确认。

## 3. 吞吐结果

| 条件 | 第 1 次（images/s） | 第 2 次 | 第 3 次 | 中位数 | 最小–最大 |
| --- | ---: | ---: | ---: | ---: | ---: |
| single-1 | 1.1255 | 1.0829 | 1.2519 | 1.1255 | 1.0829–1.2519 |
| single-2 | 2.6198 | 2.4284 | 2.6251 | 2.6198 | 2.4284–2.6251 |
| pool | 3.3055 | 3.1359 | 3.3896 | 3.3055 | 3.1359–3.3896 |

先取各条件的三次吞吐中位数，再计算：

```text
P_1 = 1.125517631749139 images/s
P_2 = 2.6198235714917635 images/s
P_pool = 3.305489148828973 images/s
η = P_pool / (P_1 + P_2) = 0.8825602180
S = P_pool / max(P_1, P_2) = 1.2617220430
```

三轮 pool 吞吐均高于三轮 single-2，但样本量仅三次，未进行显著性检验或建立置信区间。`P_1 + P_2 ≈ 3.7453 images/s` 是同一服务路径下的经验参照，不能作为严格理论最大吞吐；88.26% 也不是“离最优调度只差 11.74%”的证明。
