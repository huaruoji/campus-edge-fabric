# A｜后端与集成工作清单

负责人：______　协作人员：B（Worker 与部署）、C（前端与交互）、D（测试与验收）

> 项目为两台真实电脑协同完成批量图片 OCR。当前技术团队共 4 人，你负责中央服务、接口契约、后端测试与集成。完整接口以[项目总览](00_项目总览.md)第 4 节为准。

## 1. 你的交付范围

- `server/`：FastAPI 服务、SQLite 状态、图片与结果存储。
- `docs/api.md`：接口、字段、状态、错误、调用示例。
- `tests/backend/`：并发领取、幂等回传、旧结果、重试测试。
- 后端依赖版本、配置样例和启动方式，交给 B 汇总部署、D 汇总 README。
- 集成版本：第一天保存一个能跑通的版本，第二天中午冻结功能。

## 2. 模块清单

### 数据与状态

- [ ] Batch：ID、提交时间、文件顺序；进度从任务计数推导。
- [ ] Task：图片、状态、当前节点、尝试编号、起止时间、结果、错误。
- [ ] Worker：设备信息、最近心跳、当前任务、资源采样、完成数。
- [ ] Attempt 或等效审计记录：保留每次处理的节点、编号、状态和耗时。
- [ ] 初始任务 `queued`、`attempt=0`；每次成功领取时尝试编号递增。
- [ ] 单进程服务，领取和结果提交使用事务保护。

### 用户接口

- [ ] 批量 JPG/PNG 上传；校验类型、大小与解码尺寸，安全生成存储文件名。
- [ ] 批次查询返回总量、五种状态计数、按输入顺序排列的任务。
- [ ] 返回原图与 OCR 文字，未完成时不伪造结果。
- [ ] ZIP 包含成功文字文件及全部任务的 `manifest.csv`，保留失败原因。
- [ ] `failed/interrupted` 可手动重试；`running/succeeded` 重试返回 `409`。
- [ ] 节点查询提供在线、忙闲、资源采样和完成数。

### Worker 接口

- [ ] 注册、心跳、领取、受保护的图片下载、结果回传。
- [ ] 注册重试避免为同一稳定节点创建大量重复记录；与 B 约定重启识别方式。
- [ ] 无任务返回 `204`；有任务原子设置为 `running`。
- [ ] 回传校验节点、任务、尝试编号和当前状态。
- [ ] 已接受的同一结果重发幂等确认，不重复计数；冲突结果返回 `409`。
- [ ] 超过失联阈值时节点离线，当前任务进入 `interrupted`。
- [ ] 失联后的旧结果不得直接恢复为成功；手动重试后新领取生成新编号。
- [ ] 心跳扫描不依赖前端是否打开；数据库操作不长时间阻塞 API。

### 权限与错误

- [ ] 区分浏览器凭据和 Worker 凭据，不把密钥写入日志。
- [ ] Worker 仅访问自己当前任务的输入，不接受任意 Shell 命令。
- [ ] 统一应用错误格式 `code/message`，包括参数校验异常。
- [ ] 对上传边界、空批次、未知任务和非法状态给出可读说明。
