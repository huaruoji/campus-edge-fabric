# C｜前端与交互工作清单

负责人：______　协作人员：A（后端）、B（Worker 与部署）、D（测试与验收）

> 当前技术团队共 4 人。你负责用户能够真实完成上传、查看进度、获取结果和失败重试。测试统筹、性能报告和 README 汇总由 D 负责，你提供页面自测与使用说明。完整接口以[项目总览](00_项目总览.md)第 4 节为准。

## 1. 你的交付范围

- `web/`：一个可操作的网页，分上传、批次结果、节点状态三个区域。
- 页面配置和启动方式、用户操作说明、页面自测记录。
- 对接 A 的真实接口，配合 D 做端到端验证与技术演示。
- 页面缺陷由你修复；不承担性能统计脚本、设备环境安装或全项目报告编写。

## 2. 页面工作清单

### 上传区域

- [ ] 支持一次选择多张 JPG/PNG，显示文件名与数量。
- [ ] 显示支持范围：清晰中英文印刷体；不承诺手写、复杂表格或公式。
- [ ] multipart 使用多个 `files` 字段上传，顺序与用户选择一致。
- [ ] 显示上传中状态，禁用重复提交，处理大小/格式/网络错误。
- [ ] 上传成功后保存真实批次 ID，进入进度查询。
- [ ] 没有 Worker 在线时仍可排队，但页面明确说明等待设备接入。

### 批次与结果区域

- [ ] 每 2 秒查询批次，显示总数和排队、运行、成功、失败、中断数。
- [ ] 任务按 `position` 排列，显示文件名、状态、设备、耗时和错误。
- [ ] 原图与识别文字对照，支持长文字滚动、选择和复制。
- [ ] OCR 输出按纯文本显示，不作为 HTML 执行。
- [ ] 未完成任务不显示伪造结果，失败与中断不能显示为成功。
- [ ] 仅失败/中断任务显示重试按钮，请求期间禁止重复点击。
- [ ] 重试后重新查询服务端状态，不擅自改成成功或运行中。
- [ ] 下载 ZIP，明确包含成功结果和完整处理清单；部分失败不显示“全部成功”。
- [ ] 查询和下载失败给出可读提示与再次操作入口。

### 节点区域

- [ ] 显示真实节点名、在线/离线、忙闲、CPU、内存和完成数。
- [ ] 在线与忙闲分别显示；没有有效采样时显示“暂无数据”。
- [ ] CPU 利用率只表示忙碌程度，不标成有效吞吐或算力聚合效率。
- [ ] 样式优先清楚可读，保证评委看得见两台设备的实际参与。

## 3. 接口对接表

| 页面操作 | 接口 | 必须对齐的事项 |
| --- | --- | --- |
| 上传 | `POST /api/batches` | `files` 多文件，响应 `batch_id,total` |
| 进度 | `GET /api/batches/{id}` | 用 `counts/tasks` 渲染，不根据时间猜进度 |
| 原图 | `GET /api/tasks/{id}/input` | 使用用户访问凭据；可用 fetch 获取 Blob |
| 文字 | `GET /api/tasks/{id}/result` | `text` 可为空；错误读 `error.message` |
| 下载 | `GET /api/batches/{id}/download` | 带凭据获取 ZIP，正确处理错误响应 |
| 重试 | `POST /api/tasks/{id}/retry` | 空 JSON；处理 `409` 状态冲突 |
| 节点 | `GET /api/workers` | 读取 `workers` 数组，采样值可能为 `null` |

- 第一日 10:00 前取得 A 的响应样例，确认字段、错误和鉴权方式。
- 用户凭据只用于用户接口；不把 Worker 密钥放进前端。
- 服务端时间显示为可读本地时间，`duration_ms` 转秒时保持单位正确。
- 前期样例数据只用于开发；第一天晚间所有主流程必须接真实服务。

## 7. 页面自测清单

- [ ] 成功上传多张新图并保留顺序，连续点击不会造成意外重复提交。
- [ ] 排队、运行、成功、失败、中断均有可读展示。
- [ ] 两台设备真实在线时显示正确名称和任务归属。
- [ ] 原图与文字对应，长文件名、长文本不会破坏布局。
- [ ] 单个文件失败不会把整个批次误显示为成功。
- [ ] 重试后按服务端返回刷新，不继续显示旧成功结果。
- [ ] 下载错误不会保存成“正常 ZIP”；正常 ZIP 能打开。
- [ ] 无设备、接口断开、鉴权失效时有明确提示。
- [ ] 刷新页面后可用批次 ID 重新查询，或提供清楚的恢复入口。
- [ ] 凭据未写入源码、日志或截图，输出文字不作为 HTML 执行。

**工作优先级：真实上传与结果 → 设备与错误反馈 → 重试和下载 → 联调自测 → 简洁美化。** 不增加聊天框、摘要、复杂仪表盘等与本次技术闭环无关的功能。
